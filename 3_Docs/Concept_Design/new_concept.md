# GACHA-BIN — Concept Design & System Specification (Version 2.0)

> เอกสารพิมพ์เขียวแนวคิดการออกแบบระบบตู้รีไซเคิลอัจฉริยะและคัดแยกขยะอัตโนมัติ (Update v2.0)  
> สถาปัตยกรรม: Display-Only Kiosk + Mobile QR Authentication + Dual MG995 Servo Sorting + Web GPIO Tuner

---

## 1. ภาพรวมแนวคิดหลัก (Core Concept v2.0)

เนื่องจากหน้าจอประจำตู้เป็นจอแสดงผลแบบธรรมดา (Non-Touch Display) และกล้อง AI ถูกติดตั้งไว้ภายในห้องสแกนขวดด้านในตู้ ระบบจึงใช้แนวคิด **"Mobile-to-Kiosk Session Sync"**:
- ผู้ใช้งานใช้สมาร์ทโฟนสแกน **QR Code** บนหน้าจอตู้เพื่อลงชื่อเข้าใช้และเปิดเซสชัน
- ระบบล็อกคิวหน้าตู้ให้ผู้ใช้งานทีละ 1 คน (Single-Session Lock)
- กล้องภายในตู้ตรวจจับขวดพลาสติกและกระป๋องโลหะแบบอัตโนมัติ แล้วสั่งงานเซอร์โวมอเตอร์ **MG995 จำนวน 2 ตัว** เพื่อคัดแยกขยะลงถังซ้ายและขวา พร้อมแสดงแอนิเมชันการ์ตูนและสะสมคะแนนลงฐานข้อมูล

## 2. ลำดับการทำงานของระบบ (System Operational Flow)

### ขั้นที่ 1: หน้าจอเริ่มต้นหน้าตู้ (Standby Screen — `index.html`)
1. **การเชื่อมต่อเครือข่าย (Wi-Fi Connection):**
   - ตัวเครื่อง (Raspberry Pi / PC) เชื่อมต่อกับ Wi-Fi ปกติ (จาก Router หรือจาก Mobile Hotspot)
   - แสดง **ชื่อวง Wi-Fi (SSID)** และ **หมายเลข IP Address** ล่าสุดของตู้อย่างชัดเจนบนหน้าจอ
2. **Card นาฬิกาดิจิทัล (Real-time Clock & Date Card):**
   - แสดงเวลาปัจจุบันรูปแบบ `HH:MM:SS` และวันที่รูปแบบ `DD:MM:YY` อัปเดตแบบ Real-time
3. **QR Code สำหรับเข้าใช้งาน:**
   - สร้าง QR Code อัตโนมัติจาก IP ของตู้ เพื่อให้ผู้ใช้งานที่เกาะ Wi-Fi วงเดียวกันสแกนเข้าสู่หน้าล็อกอินบนมือถือ

### ขั้นที่ 2: การสแกน QR ล็อกอิน และการล็อกเซสชัน (Mobile Auth & Session Lock)
1. **หน้าลงทะเบียน/เข้าสู่ระบบบนมือถือ:**
   - เมื่อสแกน QR Code มือถือจะเปิดลิงก์เข้าสู่หน้ากรอกข้อมูล `username` และ `phone_number`
   - หากมีประวัติเบอร์โทรในระบบแล้ว จะดึง `key_id` และคะแนนสะสมเดิมขึ้นมาทันที หากยังไม่มีจะสร้างผู้ใช้ใหม่พร้อม `key_id` อัตโนมัติ
2. **การล็อกคิวใช้งานหน้าตู้ (Active Session Lock):**
   - เมื่อล็อกอินสำเร็จ หน้าจอใหญ่ของตู้จะสลับจากหน้า Standby (`index.html`) ไปยัง **หน้า Dashboard สะสมแต้ม** ทันที พร้อมแสดงชื่อ `username` ของผู้ใช้งานคนนั้น
   - **ล็อกเซสชัน (Session Lock):** ป้องกันไม่ให้มือถือเครื่องอื่น (IP อื่น) แย่งเข้าใช้งานซ้อน หากมีคนอื่นสแกนเข้ามาในระหว่างนี้ มือถือของคนถัดไปจะขึ้นสถานะ **"กำลังมีผู้ใช้งานอยู่ กรุณารอสักครู่ (Waiting in Queue)"** จนกว่าคนปัจจุบันจะสะสมแต้มเสร็จ

### ขั้นที่ 3: การตรวจจับขวดด้วย AI และการคัดแยกด้วย Servo 2 ตัว (AI Vision & Dual Servo Sorting)
1. **การตรวจจับอัตโนมัติ (Auto-Detection):**
   - เมื่อผู้ใช้นำขวดใส่ในช่องสแกน กล้องภายในตู้จะประมวลผลภาพอย่างต่อเนื่อง
   - หากเป็นห้องว่าง (`empty`) ระบบจะอยู่ในสถานะรอ (`Auto-Detect Standby`)
   - ระบบประมวลผลจนได้ลอจิกที่ชัดเจนและมั่นใจว่าเป็น **`plastic`** หรือ **`metal`**
2. **การให้คะแนน:**
   - ขวดพลาสติก (`plastic`) = **+1 คะแนน**
   - กระป๋องโลหะ (`metal`) = **+2 คะแนน**
3. **กลไกการคัดแยก 2 จังหวะด้วยเซอร์โวมอเตอร์ MG995 จำนวน 2 ตัว (2-Stage Sorting Mechanism):**
   - **จังหวะที่ 1 (Servo 1: ปรับองศาทิศทางรางปล่อย / Direction Diverter):**
     - ตำแหน่งตั้งต้น (Neutral Center): ตั้งฉากกึ่งกลางที่ 90 องศา
     - เมื่อ AI ตรวจพบ **`plastic`**: Servo 1 หมุนเบี่ยงทิศทางราง (เช่น 90° - 45° = 45°) เอียงไปทาง **ถังฝั่งซ้าย**
     - เมื่อ AI ตรวจพบ **`metal`**: Servo 1 หมุนเบี่ยงทิศทางราง (เช่น 90° + 45° = 135°) เอียงไปทาง **ถังฝั่งขวา**
   - **จังหวะที่ 2 (Servo 2: ปัดขวดออกจากกระบอก / Bottle Pusher Arm):**
     - เมื่อ Servo 1 เบี่ยงทิศทางเสร็จเรียบร้อย Servo 2 จะเริ่มทำงานทันที โดยหมุนก้านปัดด้วยความเร็วนุ่มนวลเพื่อผลัก/ดันขวดออกจากกระบอกรางเลื่อน ให้ตกลงสู่ถังขยะเป้าหมาย
   - **จังหวะที่ 3 (การคืนตำแหน่งเดิม / Reset to Home):**
     - Servo 2 หมุนก้านปัดกลับเข้าตำแหน่งเดิม (Retract Home)
     - Servo 1 หมุนรางกลับมาตั้งฉากกึ่งกลางที่ 90 องศา พร้อมรับขวดชิ้นถัดไป

### ขั้นที่ 4: หน้าตั้งค่าฮาร์ดแวร์ผ่านเว็บแอป (Web GPIO & Dual-Servo Configuration)
- ผู้ดูแลระบบสามารถตั้งค่าพารามิเตอร์ของ Servo ทั้ง 2 ตัวผ่านหน้าเว็บแอปได้โดยตรง (ไม่ต้องแก้โค้ดใน Thonny):
  - **Servo 1 (Direction Diverter):**
    - กำหนดขา GPIO (เช่น `GPIO12`)
    - กำหนดองศากึ่งกลาง (Center Angle เช่น `90°`)
    - กำหนดองศาเอียงซ้ายสำหรับ Plastic (เช่น `45°`)
    - กำหนดองศาเอียงขวาสำหรับ Metal (เช่น `135°`)
  - **Servo 2 (Bottle Pusher):**
    - กำหนดขา GPIO (เช่น `GPIO13`)
    - กำหนดทิศทาง/ค่าความเร็วการหมุนปัดขวด
    - กำหนดเวลาในการปัด (Push Duration เช่น `1200ms`) และเวลาหมุนกลับ (Retract Duration)
  - **ปุ่มทดสอบสด (Live Hardware Testing):**
    - ปุ่ม [ทดสอบเอียงซ้าย Plastic] / [ทดสอบเอียงขวา Metal] / [ทดสอบกึ่งกลาง 90°]
    - ปุ่ม [ทดสอบก้านปัด Servo 2]

### ขั้นที่ 5: แอนิเมชันการ์ตูนหน่วงเวลา 5 วินาที (Cartoon Feedback & Hold Timer)
- เมื่อเซอร์โวมอเตอร์ทั้ง 2 ตัวทำงานคัดแยกขวดลงถังเสร็จสิ้น:
  - ระบบจะหน่วงเวลา (Timer) ค้างจังหวะไว้ **5 วินาที**
  - บนหน้าจอแสดงผลของตู้กาชาจะแสดง **แอนิเมชันการ์ตูนน่ารักๆ** พร้อมแจ้งเตือนคะแนนที่ได้รับ เพื่อสร้างความเพลิดเพลินและรอให้ขวดตกลงสู่ถังขยะอย่างสมบูรณ์

### ขั้นที่ 6: การจบเซสชันและวนลูปใหม่ (Logout, Auto-Timeout 60s & Session Loop)
- **ตัวนับเวลาตัดเซสชันอัตโนมัติ (Inactivity Auto-Timeout):**
  - ตั้งค่าเริ่มต้นไว้ที่ **60 วินาที** (`session_timeout_sec = 60`) พร้อมแสดงตัวเลขถอยหลังบนหน้าจอตู้และมือถือ
  - รีเซ็ตเวลากลับเป็น 60 วินาทีทุกครั้งที่มีการหยอดขวดเพิ่มหรือกดทำรายการบนมือถือ (Super Admin สามารถปรับแก้เวลาได้ในหน้าตั้งค่า)
- เมื่อผู้ใช้งานทำรายการเสร็จสิ้น (กดปุ่ม Logout บนมือถือ หรือหมดเวลา Inactivity Timeout 60 วินาที):
  - ระบบทำการบันทึกคะแนนและประวัติลงฐานข้อมูล
  - ปลดล็อกเซสชัน (Unlock Session)
  - หน้าจอตู้สลับกลับสู่หน้าแรก (Standby QR Code) เพื่อรอรับผู้ใช้งานคนถัดไปเป็น Loop อย่างสมบูรณ์

## 4. ระบบของรางวัลและการสุ่มกาชาปอง (Gacha Reward System — 20 Points Threshold)

### 1. เกณฑ์แต้มและการโชว์รางวัลหน้าตู้ (Showcase on Standby Screen)

### 4. ข้อควรระวังด้านความปลอดภัยทางไฟฟ้าและฮาร์ดแวร์ (Hardware Safety Notice)
- **ระดับแรงดันสัญญาณ Ultrasonic (HC-SR04):** เซนเซอร์ Ultrasonic แบบ HC-SR04 ส่งสัญญาณ `Echo` กลับมาเป็นระดับ **5V** ในขณะที่ขา GPIO ของ Raspberry Pi รองรับแรงดันได้ไม่เกิน **3.3V**
- **การป้องกันชิป GPIO เสียหาย:** จำเป็นต้องต่อวงจรแบ่งแรงดัน (Voltage Divider ใช้ตัวต้านทาน เช่น $1\text{ k}\Omega$ และ $2\text{ k}\Omega$) หรือใช้ Logic Level Shifter ที่ขา `Echo` ก่อนต่อเข้า Raspberry Pi เสมอ
- **แหล่งจ่ายไฟของ Servo MG995:** เซอร์โวมอเตอร์ MG995 จำนวน 2 ตัวกินกระแสกระชาก (Stall Current) สูงถึง 1.2A - 1.5A ต่อตัว ควรจ่ายไฟ 5V-6V จากแหล่งจ่ายแยกภายนอก (External Power Supply / Buck Converter) โดยต่อ Ground (GND) ร่วมกับ Raspberry Pi เพื่อป้องกันบอร์ด Raspberry Pi รีบูตตัวเองขณะหมุนราง
